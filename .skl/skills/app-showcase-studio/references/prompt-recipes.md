# Studio mockup prompt recipes

## Quiet design studio

```text
Use case: product-mockup
Input images: Image 1 is the authentic application screenshot and must appear unchanged on the display.
Primary request: create a photorealistic editorial product photograph of the application displayed in a quiet contemporary design studio.
Scene/backdrop: restrained warm-gray studio, natural desk material, minimal surrounding objects, no brand logos.
Subject: one desktop display showing Image 1 edge-to-edge at the correct aspect ratio.
Composition/framing: three-quarter desk view, landscape crop, display is the clear focal point, generous calm negative space.
Lighting/mood: soft overcast window light with controlled shadows and subtle film grain.
Constraints: preserve every visible UI element, word, image, color, spacing, and proportion from Image 1; do not redesign or regenerate the interface; no extra text; no watermark.
```

## Gallery close-up

```text
Use case: product-mockup
Input images: Image 1 is the authentic application screenshot and must remain unchanged.
Primary request: create a photorealistic close-up product photograph of a slim desktop display presenting the application in a refined creative workspace.
Scene/backdrop: softly blurred neutral studio background with subtle paper and brushed-metal textures.
Subject: the display and Image 1, crisp and front-facing with only slight perspective.
Composition/framing: close crop, screen fills most of the image, landscape editorial framing.
Lighting/mood: diffused studio light, quiet premium tone, realistic reflections kept away from legible UI.
Constraints: preserve the supplied interface exactly; no invented controls, altered thumbnails, misspelled text, logos, people, or watermark.
```
