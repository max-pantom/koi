# Project mockup prompt recipes

Use only the recipe matching the source material. Replace bracketed values with project-specific facts; do not add objects or copy the user did not request.

## Software or app interface

```text
Use case: product-mockup
Asset type: [portfolio hero / README image / launch visual]
Input images: Image 1 is the authentic interface capture and must remain unchanged.
Primary request: present Image 1 on [a desktop display / laptop / phone / tablet] in a believable [setting].
Composition/framing: [front-facing / three-quarter / close crop], with the interface legible and dominant.
Lighting/mood: restrained light with reflections kept away from important UI.
Constraints: preserve every visible control, word, image, color, spacing, and proportion from Image 1; do not regenerate the interface; no extra text, logos, or watermark.
```

## Website or browser experience

```text
Use case: product-mockup
Asset type: [case-study image / launch visual]
Input images: Image 1 is the authentic webpage capture and must remain unchanged.
Primary request: place the webpage in a realistic browser or device presentation suited to [audience/context].
Composition/framing: keep the primary page section readable; preserve its original aspect ratio; use only enough browser or device chrome to establish context.
Constraints: do not rewrite page copy, rearrange sections, invent UI, crop the focal content, add unrelated branding, or add a watermark.
```

## Physical product or packaging

```text
Use case: product-mockup
Asset type: [campaign image / store listing / portfolio hero]
Input images: Image 1 is the source product, dieline, label, or render; additional images are supporting views or material references.
Primary request: present the product in [setting] with realistic scale, materials, contact shadows, and perspective.
Composition/framing: [hero close-up / shelf context / top-down arrangement].
Lighting/mood: lighting that reveals form and surface without obscuring the label.
Constraints: preserve product geometry, label artwork, logo, typography, colors, and proportions; no invented claims, extra packaging text, unrelated props, or watermark.
```

## Brand or graphic artifact

```text
Use case: product-mockup
Asset type: [identity case study / poster presentation / campaign visual]
Input images: Image 1 is the exact artwork, logo, poster, or identity asset to present.
Primary request: apply Image 1 to [printed object / sign / editorial spread / environmental surface] with believable production detail.
Composition/framing: make the supplied artwork the focal point and retain readable margins.
Materials/textures: realistic paper, ink, embossing, paint, glass, fabric, or substrate appropriate to the request.
Constraints: preserve the artwork exactly; no restyling, recoloring, altered lettering, added slogans, unrelated logos, or watermark.
```

## Icon in context

```text
Use case: compositing
Asset type: [store preview / operating-system context / launch visual]
Input images: Image 1 is the exact icon to insert; Image 2 is the base context or composition reference.
Primary request: replace only [target icon/object] in Image 2 with Image 1.
Constraints: preserve the icon mark, tile, proportions, and colors; match the base scene's scale, perspective, hover state, lighting, and shadow; keep every unrelated element unchanged; no extra text or watermark.
```
