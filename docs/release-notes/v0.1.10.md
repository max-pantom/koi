# Koi 0.1.10

This release makes saving and organizing visual references faster, clearer, and easier to install.

## What’s new

- A simpler macOS right-click menu with the most useful image actions only.
- Cleaner image previews that no longer expose filenames in the interface.
- Improved keyboard navigation, focus handling, labels, and screen-reader support.
- Page and article captures can fall back to the best available page image.
- A larger Koi Capture logo and clearer browser context-menu actions.
- The installed Koi version now appears in Settings.
- Settings now includes a direct **Download extension** action.
- Complete installation and troubleshooting documentation for the desktop app and Chrome extension.

## Downloads

- macOS Apple Silicon: download the `aarch64` DMG.
- macOS Intel: download the `x64` DMG.
- Windows: download the `.msi` or setup `.exe`.
- Linux: download the `.AppImage` or `.deb`.
- Chrome: download `Koi-Capture-0.2.4.zip`, unzip it, then load its folder from `chrome://extensions` with Developer mode enabled.

Koi remains local-first: your images, tags, palettes, folders, and capture metadata stay on your computer.
