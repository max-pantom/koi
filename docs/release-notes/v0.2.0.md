# Koi 0.2.0

Koi 0.2 expands the local moodboard into a broader reference library while keeping large folders responsive.

## New

- Save clipboard images or links with Command/Ctrl+V.
- Save and play direct MP4, WebM, MOV, M4V, and OGV videos from Koi Capture.
- Save article text as Markdown and read it inside the desktop preview.
- Save media from supported X/Twitter, Instagram, TikTok, Facebook, Threads, Bluesky, and Pinterest post links instead of creating generic saved pages.
- Save visible Instagram carousel images and videos as one batch.
- Copy palette colors as HEX, RGB, or HSL.
- Use a grouped cmdk command palette and a simpler neutral search field.
- Sonner-powered desktop notifications.
- Signed in-app updates from GitHub Releases, with automatic checks and a manual Settings action.
- Ad-hoc signing for macOS bundles so downloaded builds retain a valid bundle signature.
- A standalone first-run onboarding window with a focused, solid-surface walkthrough.
- A local MCP server and bundled stdio bridge for searching, reading, viewing, and tagging a Koi library from compatible AI clients.
- An in-app feedback form that prepares a public GitHub issue with optional version diagnostics.
- A minimal responsive Koi website with light and dark appearances.

## Refined

- Thumbnail-size changes use a GPU-only FLIP animation and respect reduced-motion preferences.
- Search and keyboard focus states use neutral interface colors.
- Article and app chrome no longer produce accidental text selections.
- Scrollbar interaction no longer starts a window drag.
- The Chrome context menu exposes one Quick save and one Choose folder action.
- Pasted website links now fetch their page title, description, canonical URL, and Open Graph image; older clipboard-link captures are refreshed quietly in the background.
- Broken local previews fall back cleanly while keeping the saved file available.
- Installer and onboarding controls no longer clutter Settings; both remain available from Command-K.
- Context menus, command results, dropdowns, Settings, feedback, and MCP surfaces use clean elevation without the unwanted white outline.
- Feedback fields have persistent labels, keyboard-safe focus handling, validation, and clear public-posting copy.
- Completing onboarding is now remembered permanently, including for people upgrading from earlier onboarding versions.
- The MCP setup is centered and compact, offers Codex, ChatGPT, Claude, and generic client instructions, and keeps long commands contained.

## Faster

- Folder scans read image headers instead of decoding every full-resolution file.
- Color analysis runs in Rust during browser idle time, is cached in SQLite, and avoids retry loops for unsupported formats.
- Modified images invalidate stale palettes, while transient indexing failures stay retryable.
- MCP connections are handled concurrently and article indexing truncates Unicode safely.

## Privacy and security

- MCP binds only to the loopback interface, validates browser origins, and requires a cryptographically secure access token.
- Setup snippets keep the token masked until explicitly revealed and use the packaged sidecar path for the current platform.
- MCP responses omit local file and folder paths; Koi explains when requested library content may be sent through the user's configured AI provider.

## Koi Capture 0.3.0

- Adds direct social media discovery, video discovery, and context-menu capture.
- Extracts readable article content and bylines.
- Saves pages without preview images using a generated local cover.
- Enlarges the extension brand mark.
